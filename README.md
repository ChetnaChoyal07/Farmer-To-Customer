# 🌾 Farmer-To-Customer Marketplace
by-Anshika, Chetna and Tulsee
A mobile application that connects **farmers directly with customers**, enabling farmers to sell raw agricultural products without unnecessary intermediaries.

## 👥 Users

The application will support three main types of users:

* **Farmer** – Add and manage agricultural products, view orders, and sell directly to customers.
* **Customer** – Browse products, search for products, place orders, and make payments.
* **Admin** – Manage users, products, orders, and overall platform activities.

## 🛠️ Technology Stack

* **Mobile Application:** React Native
* **Frontend/Web:** React
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Machine Learning:** Python / ML
* **Version Control:** Git & GitHub

## 💳 Payment Methods

The application will support:

* Online Payment
* Cash on Delivery (COD)
